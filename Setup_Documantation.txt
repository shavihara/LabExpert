# Pendulum Tracker: Setup and Installation Instructions

This application uses Python with OpenCV to track a pendulum's motion using your webcam and calculate its oscillation period. The application consists of a Python backend with Flask that processes video frames and serves a web interface.

## Prerequisites

- Python 3.6 or higher
- Webcam connected to your computer
- A pendulum with a colored bob (preferably a bright, distinct color)

## Installation Steps

1. Create a new project directory:
   ```bash
   mkdir pendulum_tracker
   cd pendulum_tracker
   ```

2. Create a virtual environment (recommended):
   ```bash
   python -m venv venv
   
   # On Windows
   venv\Scripts\activate
   
   # On macOS/Linux
   source venv/bin/activate
   ```

3. Install required packages:
   ```bash
   pip install opencv-python numpy matplotlib flask
   ```

4. Save the Python script as `app.py` in your project directory.

5. Create a `templates` folder and save the HTML template:
   ```bash
   mkdir templates
   ```
   Then save the index.html file in the templates folder.

## Running the Application

1. Start the server:
   ```bash
   python app.py
   ```

2. Open your web browser and navigate to:
   ```
   http://127.0.0.1:5000
   ```

3. Follow the on-screen instructions to start tracking your pendulum.

## Usage Tips

1. **Color Adjustment**: Use the HSV sliders to isolate the color of your pendulum bob. Adjust them until only the pendulum bob is highlighted.

2. **Lighting**: Ensure consistent lighting for best results. Avoid strong backlighting.
